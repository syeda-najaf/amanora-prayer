AZAN SOUND
Add your licensed Azan recording (30-60 seconds recommended) as:
  1) public/audio/azan.mp3                       (used in the browser and the in-app preview)
  2) android/app/src/main/res/raw/azan.mp3       (used by Android notifications; file name must stay lowercase "azan")
Then run: npm run build && npx cap sync android
